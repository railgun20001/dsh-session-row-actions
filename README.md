# dsh-session-row-actions —— 会话行悬浮按钮

把侧栏会话行悬停时行尾那排按钮变成**可配置的一排**：官方「…」菜单里的每个动作
都能勾选成悬浮按钮，并按自己的顺序排列。

```
悬停一行会话  →   （…）  归档会话  分叉会话        ← 默认：只勾了「归档」「分叉」
在行上右键    →   官方「…」菜单（0.2.2+ 原生支持，旧版由插件兼容桥打开）
```

## 安装

```powershell
npm install dsh-session-row-actions
```

也可以在 DSH 的「插件」页点「添加插件」，选择本地克隆的 `dsh-session-row-actions`
目录。安装后宿主半随 profile 热加载，客户端半需要刷新一次页面（`Ctrl+R`）。

## 配置在哪

**插件管理 → 会话行悬浮按钮**（本插件详情页），不在「设置 → 通用」。

界面是两个列表，**各管各的事**：

| 列表 | 内容 | 操作 |
| --- | --- |
| **悬浮按钮** | 第一行固定是「更多（…）」，其余是已勾选的动作（= 悬停时实际显示的那排） | 「更多」只可切显隐；其余可拖动排序、取消勾选即移出 |
| **更多菜单** | 其余动作，按官方菜单分组固定展示：置顶 / 重命名 / 分叉 / 复制 Session ID / 归档（不含「更多」） | **只可勾选**，不可拖动 |

使用要点：

- **「更多（…）」位置固定**：永远排在悬浮列表第一行、也永远在悬浮条最前，不能拖动也不能
  移除，只有勾选框控制显隐。在会话行上点右键也能打开同一份菜单。
- **两个列表互不干扰**：拖动「悬浮按钮」列表不会改动「更多菜单」；勾选新动作时按官方
  分组顺序插进悬浮条，之后可以再拖到想要的位置。
- **官方「…」菜单本身不受影响**：本插件只改变悬停时那一排按钮，官方菜单的显示顺序
  保持原样。

## 已知边界

- 需要 DSH 0.2.x 的会话行插槽；在 0.2.2+ 上右键菜单由官方原生提供，本插件自动让位，
  不与之打架。
- 配置即时生效、无需重启，保存在本机浏览器（localStorage），不涉及任何网络请求。
